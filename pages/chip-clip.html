Chip Clip

The goal of this project was to The most intensive part of this project was in creating our own spring for a specific system, and we'd all individually already done something similar for a previous problem in the same class. The method by which we found our spring was by creating a region that satisfied the strength criteria and then selecting an optimal spring within that region, leaning towards more coils, while making sure that the non-normal number of coils were within a region that would give good angles. I then designed the body of the clip around the selected spring with two identical pieces, adding a mechanical stop at the outlined full range of motion to ensure it couldn't extend further. This project wasn't as strenuous as the geartrain project, but the work in finding the spring I thought was interesting enough to include.
